### ✈️ Travel & Tourism Management System

![Java](https://img.shields.io/badge/Java_21-ED8B00?style=flat-square&logo=openjdk&logoColor=white)
![Spring Boot](https://img.shields.io/badge/Spring_Boot_3.3-6DB33F?style=flat-square&logo=springboot&logoColor=white)
![MySQL](https://img.shields.io/badge/MySQL-4479A1?style=flat-square&logo=mysql&logoColor=white)
![OpenAPI](https://img.shields.io/badge/OpenAPI_3-85EA2D?style=flat-square&logo=swagger&logoColor=black)
![Tests](https://img.shields.io/badge/28_tests-passing-brightgreen?style=flat-square)

A booking backend built around one hard problem: **never selling the same seat twice.** Bookings reserve seats atomically, cancellations restore them, and packages flip to `SOLD_OUT` and back automatically.

- 🎫 Transactional seat engine with overbooking prevention
- 🔎 Multi-criteria package filtering (price, duration, destination, status, keyword)
- 🧱 Layered architecture with DTO and mapper layers, no entity exposure
- 📖 Swagger UI, Postman collection, global exception handling
